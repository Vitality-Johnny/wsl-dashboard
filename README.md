## ✨ 功能

| 模块 | 内容 |
|------|------|
| 🖥️ **系统信息** | 用户名、主机名、OS 版本、Kernel、运行时间、CPU 占用、内存用量、磁盘用量、IP 地址 |
| 🌤️ **天气** | 当前温度、天气状况（☀️☁️🌧️❄️等）、湿度、风速。数据来源：Open-Meteo（免费，无需 API Key） |
| 📋 **待办事项** | 从 `~/.dashboard_todos.json` 读取，支持增删改 |

---

## 📦 安装

```bash
# 1. 复制脚本到 PATH
cp dashboard.py ~/.local/bin/dashboard
chmod +x ~/.local/bin/dashboard

# 2. 加到 .bashrc 自动启动（仅在交互终端显示）
echo '[[ "$TERM" != "dumb" ]] && command -v dashboard && dashboard' >> ~/.bashrc

# 3. 编辑你的待办事项
echo '{"todos": ["写代码", "运动", "早睡"]}' > ~/.dashboard_todos.json
```

完成后新开终端即可看到仪表盘。

## 🔧 配置

### 待办事项

编辑 `~/.dashboard_todos.json`：

```json
{
  "todos": [
    "完成实验报告",
    "复习高数",
    "跑步 30 分钟",
    "学英语"
  ]
}
```

### 天气城市

修改 `dashboard.py` 顶部：

```python
WEATHER_CITY = "上海"  # 改为你的城市
```

支持：上海、北京、广州、深圳、杭州、成都、武汉、南京（内置坐标，无需联网查询）。

其他城市会自动调用 Open-Meteo Geocoding API 获取坐标。

### 取消开机自启

```bash
# 编辑 .bashrc，删掉 dashboard 那行
sed -i '/dashboard/d' ~/.bashrc
```

## 🧩 技术细节

- **语言**: Python 3（仅使用标准库，无外部依赖）
- **系统信息**: 读取 `/proc` 文件系统 + shell 命令
- **天气**: Open-Meteo API（免费，无需 API Key，无需注册）
- **待办**: 本地 JSON 文件
- **代理兼容**: 自动检测 `https_proxy` 是否可用，不可用时直连

### 为什么用 Python 不用 shell？

Python 在字符串处理、JSON 解析、网络请求、错误处理方面远强于 shell 脚本，仪表盘需要同时处理系统命令、API 调用、文件读写和复杂排版——Python 更适合。
